TrueNAS Google Backup

TrueNAS Google Backup is a private tool. It copies its owner's own files from a home server to the owner's own Google Drive, then checks that each file arrived intact.

It has one user, its owner. It is not offered to the public and does not access anyone else's data.

Run by Butter Systems, the software branch of Elevare Studios.
